# Python Application Log Analyzer

## Project Overview
A Python-based application log analyzer that reads
application log files, extracts timestamps and log
levels using Regular Expressions, and generates
an analysis report.

## Features
- Reads application log files
- Extracts timestamps, log levels and messages
- Counts ERROR, WARNING and INFO entries
- Identifies invalid log entries
- Generates a text-based analysis report
- Handles missing files and unexpected errors

## Technologies Used
- Python 3
- Regular Expressions (re)
- File Handling
- Exception Handling
- OS Module
- Git and GitHub

## Project Structure
- main.py
- Logs/Application.log
- Reports/analysis_report.txt

## How to Run

1. Install Python 3.
2. Clone this repository.
3. Open the project directory.
4. Run:

   py main.py
